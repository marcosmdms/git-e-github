# Git & GitHub Descomplicado

> Do terminal ao primeiro push, de forma prática, visual e direta.

Uma aula interativa, 100% gratuita e open-source, para quem está começando do absoluto zero. Sem jargões, sem ` --global`, direto ao ponto.

**[👉 Acesse a aula ao vivo aqui](https://seu-usuario.github.io/aula-git-github/)** _(troque pelo seu link do GitHub Pages)_

---

### O que você vai aprender

Este curso foi desenhado para quem nunca abriu o terminal antes. Ao final, você vai ter publicado seu primeiro site no GitHub Pages.

**9 Módulos práticos:**

1.  **O Terminal** - O que é, como abrir (Windows, Mac, Linux) e os 7 comandos essenciais: `pwd, ls, cd, mkdir, touch, clear`
2.  **O que é Git vs GitHub?** - A analogia da máquina do tempo
3.  **Instalação e Configuração** - Instalando Git e configurando localmente (`git config user.name`)
4.  **Seu Primeiro Repositório** - `init, status, add, commit, log` com terminal interativo
5.  **Voltando no Tempo** - `log, diff, restore` para desfazer erros sem medo
6.  **Universos Paralelos (Branches)** - Criando, alternando e mesclando branches com simulador visual
7.  **Levando para a Nuvem** - `remote, push, pull, clone`
8.  **Trabalho em Equipe** - `fork, pull request, issues`
9.  **Arquivos que Salvam Vidas** - `.gitignore, README.md` e fluxo profissional

Cada módulo inclui:
- Explicação com analogia simples
- Blocos de código prontos para copiar
- Simuladores visuais (status do Git e grafo de branches)
- 2 questões de fixação com feedback imediato
